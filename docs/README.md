# 发布与验证说明

本目录解释研究复现包的数据分发、第三方材料和验收边界，不存放公司文档、代理记忆或账号信息。

- [RELEASE.md](RELEASE.md)：公司阶段与个人阶段来源、CARLA/Three.js及第三方权重边界、数据分发方式。

`provenance`只保存经过挑选的来源核对材料；总`SOURCE_MANIFEST.json`由根项目统一维护。对外展示的实际界面截图在 `showcase/output_png/`；本地实验与浏览器配置不随仓库分发。
