## 数据与仓库包装

源码、数据与展示材料合计约460MB，其中160张原RGB为407,992,772字节，约408MB。最终体积与hash以统一来源清单和Git记录为准；本地浏览器缓存和实验产物不计入发布数据。

大量RGB、部分NPZ和个人权重通过Git LFS管理；源码、协议、截图和必要数值在普通Git文件中。克隆时先安装Git LFS并执行 `git lfs pull`；网页下载ZIP的LFS内容取决于GitHub仓库设置，不作为推荐获取方式。

`experiments/`中的本地验收产物、浏览器配置/缓存、调试日志和本地进展日记已排除。公开验收摘要位于 `docs/validation/`，实际界面截图位于 `docs/showcase/`。`inspect_predictions/便携完整回放_20261115.md`按所有者要求仅本地保留，不提交或导出。本轮未删除本地证据。来源清单里的旧路径只用于溯源，正式入口不依赖旧E/G/F盘数据。
